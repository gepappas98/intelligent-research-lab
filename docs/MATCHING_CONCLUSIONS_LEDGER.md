# Συμπεράσματα συστοιχίσεων — append-only μητρώο

## Κανόνας ακεραιότητας
Τα πρωτογενή δεδομένα εξάγονται αυτούσια: χωρίς αλλαγή τιμών, αφαίρεση γραμμών, αναδιατύπωση JSON ή συγχώνευση Legacy/V2/V3. Το παρόν μητρώο είναι ξεχωριστό από τα πρωτογενή δεδομένα. Κάθε συμπέρασμα πρέπει να συνδέεται με τα ακριβή αναγνωριστικά πηγών και την έκδοση της συστοίχισης που το παρήγαγε.

## Υποχρεωτική εγγραφή ανά συστοίχιση
Για κάθε ανάλυση/συστοίχιση προστίθεται νέα εγγραφή — ποτέ overwrite προηγούμενου συμπεράσματος — με:
- `conclusion_id`: σταθερό μοναδικό ID.
- `recorded_at_utc`: πότε γράφτηκε το συμπέρασμα.
- `matching_run_id` και `matching_version`: ακριβής εκτέλεση/έκδοση.
- `source_record_ids`: όλα τα IDs των πρωτογενών εγγραφών που συγκρίθηκαν.
- `source_snapshot_checksums`: checksums του ακριβούς snapshot.
- `time_window`: χρονικό παράθυρο και ζώνη ώρας.
- `hypothesis`: τι ελέγχαμε.
- `observations`: μετρήσεις και παρατηρήσεις, διακριτά από ερμηνεία.
- `conclusion`: τι υποστηρίζουν τα δεδομένα.
- `confidence` και `limitations`: αβεβαιότητα, δείγμα, missingness, πιθανό look-ahead/data leakage.
- `counterevidence`: δεδομένα που αντιτίθενται στο συμπέρασμα.
- `next_test`: συγκεκριμένος επόμενος έλεγχος.
- `status`: exploratory / replicated / contradicted / retired — ποτέ σιωπηρή αναβάθμιση σε proven edge.

## Ελάχιστοι κανόνες ερμηνείας
- Μη χαρακτηρίζεις συσχέτιση ως αιτιότητα.
- Μη συγχωνεύεις Legacy, V2 και V3 cohorts.
- Μη μετράς unresolved ως loss ούτε ως win.
- Ξεχώριζε event time, observed time, available time, decision time και entry time.
- Κατέγραφε τις παραμέτρους και τα δεδομένα που ήταν διαθέσιμα τη στιγμή της απόφασης, ώστε να μην υπάρχει look-ahead.
- Όταν μια επανάλυση αλλάζει αποτέλεσμα, κράτα και τα δύο συμπεράσματα με σύνδεση μεταξύ τους και εξήγησε γιατί.

## Κατάσταση
Το αρχείο αυτό ορίζει το απαιτούμενο συμβόλαιο καταγραφής· δεν ισχυρίζεται ότι τα παλαιότερα συμπεράσματα έχουν ήδη ανακτηθεί ή ότι το μητρώο ενημερώνεται αυτόματα. Η αυτοματοποίηση πρέπει να γράφει τις εγγραφές από το πραγματικό αποτέλεσμα κάθε matching run και να επαληθεύει ότι όλα τα source IDs υπάρχουν στο πρωτογενές snapshot.
