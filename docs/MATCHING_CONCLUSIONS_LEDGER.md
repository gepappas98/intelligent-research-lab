# Συμπεράσματα συστοιχίσεων — append-only μητρώο

## Σκοπός
Το μητρώο διατηρεί **την ερευνητική γνώση**, όχι αντίγραφο της βάσης. Δεν απαιτείται εξαγωγή πρωτογενών πινάκων ή JSON. Τα αρχικά δεδομένα παραμένουν στο canonical source. Σε χειροκίνητη ανανέωση χρησιμοποιούνται στοχευμένοι, read-only έλεγχοι για να εξαχθούν συμπεράσματα.

## Κανόνας ακεραιότητας
Κάθε συμπέρασμα πρέπει να συνδέεται με την πηγή και την έκδοση της ανάλυσης όπου αυτά είναι διαθέσιμα. Αν λείπει αναγνωριστικό run, ακριβές χρονικό παράθυρο ή πηγή, αυτό σημειώνεται ρητά ως κενό τεκμηρίωσης — δεν επινοείται. Κάθε νέα διαπίστωση προστίθεται· δεν αντικαθιστά σιωπηρά προηγούμενο συμπέρασμα.

## Υποχρεωτικά πεδία
- `conclusion_id`: σταθερό μοναδικό ID.
- `recorded_at_utc`: πότε καταγράφηκε το συμπέρασμα.
- `source_project_ref`, source table/record/run IDs και code commit/PR, όταν είναι διαθέσιμα.
- `matching_run_id` και `matching_version`, όταν υπάρχουν.
- `cohort`: Legacy / V2 / V3 / paper / shadow / live — χωρίς αυθαίρετη συγχώνευση.
- `time_window`: χρονικό παράθυρο και ζώνη ώρας ή ρητή σημείωση ότι δεν ανακτήθηκε.
- `hypothesis`: τι ελέγχαμε.
- `observations`: μετρήσεις, δείγμα, win/loss/expiry/open/unresolved counts, PnL unit και κόστη όπου είναι διαθέσιμα.
- `conclusion`: τι υποστηρίζουν τα δεδομένα, χωριστά από την ερμηνεία.
- `confidence`, `limitations`, missingness και πιθανοί κίνδυνοι look-ahead/data leakage.
- `counterevidence`: στοιχεία που αντιτίθενται στο συμπέρασμα.
- `next_test`: συγκεκριμένος έλεγχος διάψευσης/επιβεβαίωσης.
- `status`: exploratory / replicated / contradicted / retired. Η υλοποίηση δεν σημαίνει επιτυχία και το θετικό in-sample αποτέλεσμα δεν σημαίνει proven edge.

## Ελάχιστοι κανόνες ερμηνείας
- Μη χαρακτηρίζεις συσχέτιση ως αιτιότητα.
- Μη μετράς unrealized PnL ως realized profit.
- Μη χαρακτηρίζεις historical/shadow benchmark ως live ή realized paper profit.
- Μη συγχωνεύεις Legacy, V2 και V3 cohorts χωρίς ρητό κοινό πρωτόκολλο.
- Μη μετράς unresolved ως loss, win ή μηδέν.
- Ξεχώριζε event time, observed time, available time, decision time και entry time όταν είναι σχετικά.
- Κατέγραφε τις παραμέτρους και τα δεδομένα που ήταν διαθέσιμα τη στιγμή της απόφασης, ώστε να αποφεύγεται look-ahead.
- Όταν μια επανάλυση αλλάζει αποτέλεσμα, κράτα και τα δύο συμπεράσματα με σύνδεση μεταξύ τους και εξήγησε γιατί.
- Διατήρησε αποτυχίες, αρνητικά αποτελέσματα, ελαττώματα triggers και μηδενικά αποτελέσματα ως γνώση.

## Κατάσταση
Το αρχείο αυτό ορίζει το συμβόλαιο καταγραφής· δεν ισχυρίζεται ότι όλα τα ιστορικά συμπεράσματα έχουν ήδη ανακτηθεί ή ότι το μητρώο ενημερώνεται αυτόματα. Η μεταφορά είναι **conclusions-only και χειροκίνητη**. Δεν περιλαμβάνει dump, mirror πινάκων, cron ή αυτόματη ανανέωση.
